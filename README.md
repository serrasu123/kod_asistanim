# Projenin Adı: Kod-Asistan v0.1
## Projenin Amacı: Kullanıcılara günlük işlerinde (hesaplama, selamlama vb.) yardımcı olacak bir dijital asistan tasarlamak.

## Projenin Hedefleri
**v1.0 Akıllı Menü**: Kullanıcının asistan içindeki birim arasında kolayca geçiş yapabileceği etkileşimli bir menü yapısı oluşturmak.
**v2.0 Veri Saklama**: Kullanıcı verilerini kalıcı olarak depolayacak bir altyapı geliştirmek.

## Proje Kapsamı
Aşağıdaki sözde kod, asistanımızın sistem kararlılığını test etmek veya kullanıcının girdilerini belirli bir sınıra göre kontrol etmek için tasarlanan **KRİTİK EŞİK** mantığını göstermektedir:

1. BAŞLA
2. YAZ "Lütfen kontrol edilecek değeri giriniz:"
3. OKU girilen_deger
4. EĞER girilen_deger >= 50 İSE
5. YAZ "Kritik eşik aşıldı! Asistan güvenlik moduna geçiyor." ve 3. adıma git
6. DEĞİLSE
7. YAZ "Değer normal sınırlar içinde. İşlem başarılı."
8. BİTİR
